### 🚀 What I build

I write backend and frontend logic inside NetSuite — not just configure it. Day to day that looks like:

- **SuiteCommerce Advanced (SCA v2024.1)** — custom Checkout & My Account extensions; frontend built on Backbone.js + Handlebars, backend wired through SCA's Model-Service architecture into SuiteScript 2.0, deployed with EDT + Gulp
- **Celigo integrations** — Amazon Seller Central ↔ NetSuite, handling Order Import, Fulfillment Export, FBA/MFN/multi-account flows, custom JS hooks, error handling & alerting
- **SuiteBuilder (Site Builder)** — custom login/signup flows, page & category structure, template customization with HTML/CSS
- **Automation** — Saved Searches, Workflows, Custom Records/Dashboards to automate P2P and O2C processes end-to-end
